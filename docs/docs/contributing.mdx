# 🤝 Contributing to React Lingo Starter

We welcome contributions from the community! This guide will help you get started with contributing to the project.

## Ways to Contribute

### 🐛 Report Bugs
Found a bug? Please [open an issue](https://github.com/your-org/react-lingo-starter/issues) with:
- Clear description of the issue
- Steps to reproduce
- Expected vs actual behavior
- Environment details (OS, Node version, etc.)

### 💡 Suggest Features
Have an idea for improvement? [Create a feature request](https://github.com/your-org/react-lingo-starter/issues) including:
- Problem description
- Proposed solution
- Alternative approaches considered

### 📝 Improve Documentation
Help make our documentation better:
- Fix typos or unclear explanations
- Add missing information
- Create tutorials or examples
- Translate documentation

## Development Setup

1. **Fork and Clone** the repository
2. **Install dependencies**: `npm install`
3. **Create a feature branch**: `git checkout -b feature/your-feature-name`
4. **Make your changes**
5. **Test thoroughly**
6. **Submit a pull request**

## Code Guidelines

### Commit Messages
Use clear, descriptive commit messages:
```
feat: add Spanish language support
fix: resolve translation loading issue
docs: update installation instructions
```

### Code Style
- Follow existing code patterns
- Use TypeScript for type safety
- Add JSDoc comments for complex functions
- Keep components small and focused

### Testing
- Test your changes across different browsers
- Verify translations work correctly
- Check for accessibility issues
- Run existing tests: `npm test`

## Adding New Languages

1. **Update `i18n.json`** to include new language code
2. **Add language option** to the UI component
3. **Update `src/i18n.ts`** with new language import
4. **Generate translations**: `npm run i18n`
5. **Test language switching**

## Documentation Updates

When updating documentation:
- Use clear, concise language
- Include code examples where helpful
- Test all links and references
- Update screenshots if UI changes

## Pull Request Process

1. **Update documentation** if needed
2. **Add tests** for new features
3. **Ensure CI passes** all checks
4. **Request review** from maintainers
5. **Address feedback** and make revisions

## Community Guidelines

- Be respectful and inclusive
- Focus on constructive feedback
- Help newcomers get started
- Follow our [Code of Conduct](./code-of-conduct)

## Getting Help

- 📧 **Issues**: For bugs and feature requests
- 💬 **Discussions**: For questions and general discussion
- 📖 **Documentation**: Check existing docs first

Thank you for contributing to React Lingo Starter! 🎉
